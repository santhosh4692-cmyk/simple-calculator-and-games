# Simple Calculator and Games

- `index.html` - Pocket Calc & Star Catcher: a calculator and a 2D touch game that runs in any browser (phone or desktop). Open the file to play.
- `calculator.py` - a command-line calculator for +, -, *, and /.
- `guess_game.py` - a number guessing game (1 to 100).

Run the Python programs with Python 3:

    python3 calculator.py
    python3 guess_game.py
